### Implementation
All four phases implemented in one session:
- `scripts/benchmark.py` — idempotent runner, supports `--limit`, `--local-only`, `--api-only`, `--backends`
- `scripts/analyze.py` — WER metrics with configurable ground truth backend
- `scripts/report.py` — self-contained HTML with Chart.js charts, sortable table, word-level diff viewer
- `config.py` — central config for backends, model paths, cost rates, ground truth key

### Design decisions made during development
- **Ground truth**: dropped iOS reference entirely. iOS .txt files are Apple's automated transcription — not reliable ground truth. Used `gpt-4o-transcribe` output as reference instead.
- **WER normaliser**: lowercase → hyphens/dashes→space → strip punctuation → collapse whitespace. Handles mixed German/English, compound words, period-at-sentence-boundary differences.
- **Diff viewer fix**: word comparison normalises punctuation before LCS (so "Pilzen." matches "Pilzen") but displays original text.
- **Multi-backend**: refactored from single API to dynamic backend list. Each backend gets its own `results/raw/<key>/` directory. Report adapts to however many backends are present.
- **Added gpt-4o-transcribe** after discovering it's available and more accurate than whisper-1 at the same price.

### Full run results (44 files, 84.8 min audio)
| Backend | Mean RTF | WER vs gpt-4o | Cost |
|---|---|---|---|
| Local whisper.cpp | 1.067× | 0.199 | — |
| whisper-1 | 0.061× | 0.264 | $0.51 |
| gpt-4o-transcribe | 0.043× | (reference) | $0.51 |

**Surprising finding:** local WER (0.199) is lower than whisper-1 WER (0.264). Local whisper.cpp large-v3-turbo agrees more with gpt-4o-transcribe than whisper-1 does — likely because both use large-v3-turbo weights.

**Conclusion:** gpt-4o-transcribe wins on all dimensions (speed, accuracy, same cost as whisper-1). Local is too slow for pipeline use without a GPU (often >1× real-time on CPU). At $0.006/min, ~30h/month of voice notes ≈ $10.80.
